    INDEPENDENT READ-ONLY MARKET DATA

    VANTAGE DEMO quotes for LOCAL PAPER

    DISCONNECTED

    This is a second, market-data-only MT5 interface. It reads only the protected VANTAGE_DEMO profile and cannot place, modify, cancel or close broker orders. Connecting never changes the execution selector, starts a strategy, Arms, or Activates.

    Save the DEMO credential locally, then connect. Execution remains LOCAL PAPER.

    Only instruments returned by this account are shown. CFDs are labeled as CFDs, not owned shares. Fresh advancing ticks are required; stale, missing or degraded data fails closed with no replay fallback. Manual-only paper startup still requires a reviewed order for every fill.

    Listed shares & ETFs

    Owned listed instruments require an explicit symbol + exchange/MIC + currency identity and a separately entitled provider. A same-named Vantage share/ETF CFD is never a substitute. This build exposes a read-only routing-policy boundary, not listed execution.

    MANUAL & LIMITATIONS

    Read before demo or live use

    User manualAPI documentation
    Verified here

    Paper regressions and fake-MT5 unit/API/integration behavior. Windows artifacts carry their own actual test logs.

    Not thereby verified

    A real Vantage connection, account-specific instrument availability, demo fills, live execution, or profitability. These require explicit local verification.

    Live remains locked

    Real order placement needs exact identity, risk bounds, fresh data, reconciliation, Arm, Activate and final confirmation. No startup or credential auto-activation.

    TradingView later

    No restricted chart library or webhook relay is bundled. Future alerts require a secure public HTTPS relay, authentication, dedupe, timestamps and audit. Never include broker credentials.
