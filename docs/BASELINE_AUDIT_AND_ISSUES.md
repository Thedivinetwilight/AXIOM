## Executive Summary of Baseline Findings

1. **Fragmented Desktop UI (`P1`)**: The Windows launcher (`packaging/windows/axiom_launcher.py:21`) opens `/terminal`, which only wires `AXIOM_PAPER` (replay/MT5), `VANTAGE_DEMO`, and `VANTAGE_LIVE`. Upstox NSE BOD search, Upstox DPAPI token management, and NSE autonomy live on a separate `/autonomy` page (`app/static/autonomy/index.html`); Alpaca Broker has only a static read-only header badge (`#alpaca-broker-badge`) with zero controls; there is no `Strategies` workspace in `/terminal`; and `#listed-scope-badge` (`app/static/terminal/index.html:41`) claims *"listed stock/ETF broker execution is not supported in this build"*, contradicting `app/alpaca_broker/` and `app/autonomy/upstox.py`.
2. **NSE Instrument Master & Search Gaps (`P1`)**: `InstrumentCatalog.from_upstox_records` (`app/autonomy/upstox.py:766-883`) silently overwrites duplicate `instrument_key` records while double-counting `kept_by_segment` (breaking segment-sum reconciliation), collapses ETFs (`INF*` ISINs), Sovereign Gold Bonds (`SG`), Government Securities (`GS`), SME (`SM`/`ST`), and Trade-for-Trade (`BE`/`BZ`) equities into flat `EQUITY` with default `product="I"` (even where intraday MIS is exchange-prohibited), discards `NSE_INDEX` completely instead of keeping watch-only index metadata, lacks `NFKC`/zero-width Unicode normalization and exchange-prefix/ISIN/display-symbol search, and lacks `1D` historical candle support (`UpstoxReadOnly` only implements `1m` and `30m`).
3. **Disconnected Credential Stores & Misleading Connection Checks (`P1`)**: `/api/connections/` and `/api/connections/upstox/test` (`app/market_data/connection_probe.py:56`) only read `settings.market_data_access_token` from env, ignoring tokens saved in the Windows DPAPI store (`app.state.upstox_token`). Conversely, `/api/autonomy/upstox-token/test` requires a pre-loaded BOD catalog key and marks after-hours stale quotes as `ok: False`. Alpaca Market Data has no DPAPI secret store at all, and Alpaca Broker has a DPAPI store (`app/alpaca_broker/credentials.py`) with zero API/UI endpoints to save or delete credentials.
4. **US/NASDAQ Calendar, Discovery, and `AlpacaBrokerService` Safety Bugs (`P0` / `P1`)**:
   - **P0 (`ISS-06`)**: `POST /api/alpaca-broker/gate/arm` crashes in `ALPACA_LIVE` mode because `service.readiness_checks()` calls `self._require_client()`, which raises `BrokerStateBlocked("LIVE client is not bound; Arm and Activate first")` before `arm()` can ever run.
   - **P0 (`ISS-07`)**: `AlpacaBrokerService._estimated_value()` (`app/alpaca_broker/service.py:131-140`) returns `None` for share-quantity (`qty`) market orders, completely bypassing `max_order_value` and `buying_power` checks.
   - **P1 (`ISS-08`–`ISS-12`)**: `AlpacaBrokerService` keeps its order journal only in RAM (losing `INTENT` state on crash), fails to update `broker_order_id` on `PATCH` replace (breaking subsequent `reconcile()`), overcounts cumulative `filled_qty` across multiple partial fills, activates `ALPACA_LIVE` without a typed confirmation phrase or clock/session/quote-freshness checks, and runs indiscriminate `cancel_all()` during `emergency_stop` without distinguishing protective exits on open positions.
   - **P1 (`ISS-13`–`ISS-14`)**: `app/markets/us_calendar.py` miscalculates Saturday New Year's Day (`2027-12-31` falsely marked closed) and Friday July 2 (`2026-07-02`, `2027-07-02` falsely marked early-close), and `app/data/alpaca.py` only probes single-symbol `/v1/assets/{symbol}` with no `/v2/assets` NASDAQ symbol discovery, ETF classification, or persistent offline catalog cache.
5. **Missing Unified Multi-Market `LIVE-MARKET PAPER` Mode (`P1`)**: Legacy `PaperSimulator` (`app/paper_trading/service.py`) holds a single currency (`settings.currency`, defaulting to `INR` on `DEMO` replay) and cannot run NSE (`INR`) and NASDAQ (`USD`) live-market paper sessions side-by-side with realistic market-specific fee/slippage schedules, persistent sessions, strategy runners, and explicit off-hours/stale-feed state transitions.
