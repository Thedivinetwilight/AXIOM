## KNOWN LIMITATIONS
- Gap detection covers intraday cadences only; daily/weekly/monthly
  calendars would need an exchange-holiday calendar to avoid fabricating
  "missing" days (documented choice: report nothing than report wrong).
- The official instrument file has no explicit "suspended" flag; local
  states are active/removed only.
- Parquet support activates only when pyarrow is importable; the default
  store is partitioned gzip-CSV (Termux-friendly).
- Shadow performance is hypothetical paper accounting, never a trading
  result; report lines label it MODEL INTERPRETATION.
- V2.1 reports/coverage are backed by recorded local data only; on a fresh
  install they will honestly show "no recorded data" until history sync runs.
