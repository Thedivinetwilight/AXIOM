# Historical diagnostic logs (not current evidence)

These files are **historical CI evidence** kept for auditability. They were
captured by the Windows release workflow that ran at the commit recorded inside
each log and are *not* regenerated by the current workflow.

Current evidence lives in the workflow artifact
`axiom-vantage-operator-windows-x64-<VERSION>` (retention 30 days) and includes:

- `build-windows.log` — the full build/acceptance transcript,
- `pytest-full.log`, `pytest-focused.log`, `js-*.log`, `benchmark-python.log`,
- `install-test-log.txt`, `installer-test-log.txt`, `portable-test-log.txt`,
- `SHA256SUMS.txt` (commit-bound header) and `BUILD_METADATA.json`,
- `SOURCE_COMMIT.txt` — the exact source commit for that run.

Nothing under this folder is shipped in the installer or the portable ZIP; the
packaging scripts never read it. Do not add new logs here — the workflow uploads
them as artifacts instead of committing them.
